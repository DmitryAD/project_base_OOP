# project_base_OOP

Проект по ООП — базовая модель банковских счетов.

## Задание
День 1: абстрактная модель банковского счёта (AbstractAccount, BankAccount),
собственные исключения, валидация операций, строковое представление.

## Запуск демонстрации

```bash
cd src
python main.py
```
