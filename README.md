# PyBank — модель банковской системы на Python

Пет-проект: банковская система, построенная поэтапно — от одного счёта
до банка с клиентами, очередью транзакций, риск-анализом, журналом аудита,
генерацией нагрузки и отчётностью с графиками.

Проект демонстрирует объектно-ориентированное проектирование
(абстрактные классы, наследование, полиморфизм, инкапсуляция),
собственную иерархию исключений, корректную работу с деньгами,
безопасное хранение паролей и покрытие кода юнит-тестами.

## Возможности

- **Счета** (`main.py`) — абстрактный `AbstractAccount` и четыре типа счетов:
  `BankAccount` (расчётный), `SavingsAccount` (неснижаемый остаток,
  ежемесячные проценты), `PremiumAccount` (овердрафт, комиссия за снятие,
  повышенный лимит), `InvestmentAccount` (портфель акций, облигаций и ETF,
  прогноз доходности). Пять валют: RUB, USD, EUR, KZT, CNY.
- **Клиенты** (`client.py`) — проверка совершеннолетия, пароли в виде
  хеша PBKDF2-HMAC-SHA256 с индивидуальной солью.
- **Банк** (`bank.py`) — регистрация клиентов, открытие, заморозка и
  закрытие счетов, аутентификация с блокировкой после трёх неудачных
  попыток, запрет операций с 00:00 до 05:00, поиск счетов, рейтинг
  клиентов по суммарному балансу в пересчёте на одну валюту, общий
  баланс по валютам.
- **Транзакции** (`transaction.py`) — приоритетная очередь с отложенным
  исполнением и отменой, обработчик с комиссией за внешние переводы,
  конвертацией валют и повторными попытками при временных сбоях.
- **Аудит и риск-анализ** (`audit.py`, `risk.py`) — журнал событий с
  уровнями важности и записью в файл (JSON Lines); оценка риска операции
  по четырём признакам и автоматическая блокировка высокорискованных
  операций.
- **Симуляция** (`simulation.py`) — генерация клиентов, счетов и
  транзакций с воспроизводимым результатом при фиксированном `seed`.
- **Отчёты** (`reports.py`) — отчёты по клиенту, банку и рискам в
  текстовом виде, JSON и CSV; круговые и столбчатые диаграммы и график
  движения баланса (matplotlib).

## Ключевые решения

- **Деньги хранятся в `Decimal`**, а не во `float`: суммы точны до копейки,
  округление явное (`ROUND_HALF_UP`).
- **Перевод выполняется по схеме «проверить, затем применить».** Курс
  валюты и возможность зачисления проверяются до списания у отправителя,
  поэтому сбой не оставляет деньги списанными без зачисления, а повторная
  попытка не списывает сумму дважды.
- **Ошибки делятся на постоянные и временные.** Постоянные (нехватка
  средств, заблокированный счёт, запрет по риску) сразу завершают
  транзакцию, временные (недоступен сервис курсов) повторяются.
- **Единые проверки для всех путей.** Ночной запрет и риск-анализ
  применяются одинаково к прямым операциям банка и к операциям из очереди.
- **Внедрение зависимостей.** Источник времени, сервис курсов, журнал и
  анализатор рисков передаются в конструкторы, что позволяет
  детерминированно тестировать поведение в любое время суток и при сбоях.
- **Данные отделены от логики.** `Transaction` только хранит состояние,
  операции исполняет `TransactionProcessor`; модули возвращают данные, а
  вывод на экран собран в `demo_full.py`.

## Установка

Требуется Python 3.10 или новее.

```bash
git clone https://github.com/DmitryAD/project_base_OOP.git
cd project_base_OOP
pip install -r requirements.txt
```

## Запуск

```bash
python src/demo_full.py
```

Демонстрация последовательно показывает работу счетов, банка, очереди
транзакций, риск-анализа, симуляции и отчётов. Отчёты и графики
сохраняются в папку `reports_output/`.

## Тесты

```bash
python -m unittest discover -s tests
```

138 тестов покрывают все модули: счета и денежные расчёты, клиентов,
банк и аутентификацию, очередь и обработку транзакций (включая сбои
сервиса курсов и отказ получателя), аудит и риск-анализ, симуляцию и
построение отчётов. Время в тестах зафиксировано, поэтому результат не
зависит от часа запуска.

## Ограничения

Система однопоточная и хранит данные в памяти. Атомарность перевода
обеспечивается порядком операций; в многопользовательской системе для
этого нужны транзакции базы данных и блокировки. Курсы валют заданы
фиксированным справочником.
