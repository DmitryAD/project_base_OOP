# PyBank — банковская система на Python (ООП)

Учебный пет-проект: модель банковской системы, построенная поэтапно —
от единичного счёта до полноценного банка с клиентами, очередью
транзакций, риск-анализом, аудитом и системой отчётности с
визуализацией. Проект демонстрирует практики ООП (наследование,
инкапсуляция, полиморфизм, абстрактные классы), собственную иерархию
исключений, юнит-тестирование и настроенный CI на GitHub Actions.

## Возможности

- **Счета** — базовый `BankAccount` и три специализированных подтипа:
  `SavingsAccount` (накопительный, начисление процентов),
  `PremiumAccount` (овердрафт, комиссия за снятие),
  `InvestmentAccount` (инвестиционный портфель: акции/облигации/ETF).
- **Bank** — центральный класс: регистрация клиентов, открытие счетов,
  аутентификация по паролю, рейтинг клиентов по балансу, общий баланс
  банка по валютам.
- **Транзакции** — `Transaction`, приоритетная очередь `TransactionQueue`
  (на основе `heapq`), обработчик `TransactionProcessor` с комиссиями,
  конвертацией валют и логированием ошибок.
- **Аудит и риск-анализ** — `AuditLog` (журнал событий с уровнями
  важности), `RiskAnalyzer` (оценка операций по нескольким признакам:
  крупная сумма, частые операции, перевод на новый счёт, ночное время)
  с автоматической блокировкой подозрительных операций.
- **Симуляция** — `BankSimulation`: генерация случайных клиентов, счетов
  и транзакций с воспроизводимым результатом (фиксированный `seed`) —
  для нагрузочной демонстрации системы в действии.
- **Отчётность и визуализация** — `ReportBuilder`: отчёты по клиенту,
  по банку и по рискам в текстовом, JSON и CSV форматах; графики
  (круговые, столбчатые, график движения баланса) через `matplotlib`.

## Установка

```bash
git clone <ссылка на репозиторий>
cd project_base_OOP
pip install -r requirements.txt
```

## Запуск

Сквозная демонстрация всей системы одним прогоном:

```bash
python src/demo_full.py
```

Можно также запустить отдельные части системы независимо:

```bash
python src/main.py          # только счета и их подтипы
python src/simulation.py    # генерация нагрузки + пользовательские сценарии
python src/reports.py       # генерация отчётов и графиков (папка reports_output/)
```

## Тесты

```bash
python -m unittest discover -s tests
```

Тесты покрывают все модули системы: счета, клиентов/банк, транзакции,
аудит/риск-анализ, симуляцию и построение отчётов. Тесты также
автоматически запускаются в CI (GitHub Actions) при каждом пуше и
pull request в `main` — см. `.github/workflows/tests.yml`.

## Стандарты кода

Код придерживается PEP8, использует типизацию аргументов через
аннотации, разделяет данные и логику их обработки (например,
`Transaction` только хранит состояние, а `TransactionProcessor`
исполняет операции), и не полагается на глобальное состояние.
