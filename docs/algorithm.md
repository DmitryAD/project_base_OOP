# Алгоритм работы модели банковского счёта

## Структура классов

- **AbstractAccount** — абстрактный базовый класс с общими полями
  (id счёта, владелец, защищённый баланс, статус) и абстрактными методами
  `deposit`, `withdraw`, `get_account_info`.
- **BankAccount** — конкретная реализация с валидацией, статусами
  и поддержкой валют.

## Логика операций

1. Перед любой операцией проверяется статус счёта:
   - `frozen` → `AccountFrozenError`
   - `closed` → `AccountClosedError`
2. Сумма операции проверяется на корректность (число, положительное значение),
   иначе — `InvalidOperationError`.
3. При снятии средств проверяется достаточность баланса,
   иначе — `InsufficientFundsError`.

## Генерация ID

Если номер счёта не передан явно, генерируется короткий UUID (8 символов)
через `uuid.uuid4()`.
